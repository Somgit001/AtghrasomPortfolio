# Som Athghara — Portfolio

Live at [atghrasom.tech](https://atghrasom.tech)

Personal portfolio site for **Som Athghara**, an aspiring Cloud & DevOps Engineer specializing in AWS, Azure, Linux, Docker, CI/CD, and Data Analytics. BCA graduate from Sri Sri University, Cuttack.

## What's here

This repo hosts the **statically exported build** of the portfolio, served via GitHub Pages on a custom domain. It's generated output — not meant to be hand-edited directly (see "Source" below).

## Sections

- **Home** — intro, quick links, social profiles
- **About** — bio, skills (Cloud & DevOps, Data Analytics, Programming, Front-End), work experience, education
- **Projects** — filterable by category:
  - Cloud & DevOps (CI/CD pipelines, EKS microservices, IAM hardening, cost monitoring, Terraform automation)
  - Data Analytics (SQL/Excel sales dashboards)
  - Storage Administrator (iSCSI SAN lab, NAS monitoring lab)
  - Other (Resume.AI, JobTrack, JobHunt AI, Live Recruiter Feed)
- **Contact** — direct message form (Web3Forms) and an offline portfolio chatbot that answers from this site's own content — no external AI calls

## Tech stack

Next.js 15 (static export) · React · Tailwind CSS · Framer Motion · Web3Forms

## Deployment

Built with `next build` (`output: "export"` in `next.config.js`) and pushed as static files to this repo's `main` branch, served via GitHub Pages with a custom domain (`CNAME`) and `.nojekyll` to preserve the `_next/` asset folder.
